Description
This experiment evaluates AI models' ability to optimize and improve the performance of an image upload feature in a social media platform. In Project A, the image upload functionality suffers from significant delays during high traffic times, especially when users upload large images. The slow processing of images and potential server overloads cause uploads to fail or retry, resulting in poor user experience. In Project B, the upload functionality is optimized to handle large image sizes more efficiently, reduces server load, and ensures smoother uploads even during peak traffic. The goal is to implement optimizations that significantly improve the upload speed and overall reliability of the image upload feature.
Key objectives:
1.	Replicate the original slow image upload functionality in Project A with performance bottlenecks.
2.	Optimize the image upload functionality in Project B by reducing the processing time and handling large images and network latencies more efficiently.
3.	Verify the improvements with automated performance tests and visual evidence.
4.	Quantify the improvements in upload speed, success rate, and user experience.
